# Vacations

Cardoso family trip planners. Each subdirectory is a self-contained, single-file static site for one trip.

- `argentina/` — May 2026, Kit's graduation trip with Mom. Anchor-picking flow + itinerary + lodging.

The root `index.html` is the chooser that lists available trips.

## Local preview

```
open index.html
```
